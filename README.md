# Payadus Project — site

Portfólio publicado no GitHub Pages, com uma [página dedicada ao Payadus Multiverse](payadus-multiverse.html).

- `index.html`: portfólio e destaque para o Multiverse.
- `payadus-multiverse.html`: apresentação do jogo e da Payadus Engine.
- `assets/`: logo, artes e capturas de tela usadas pelo site.

O site é estático: HTML, CSS e JavaScript, sem etapa de compilação. Para publicar
alterações, envie estes arquivos à branch `main`. Em **Settings → Pages**, a
origem deve ser **Deploy from a branch → main → /(root)**.

Os aplicativos para Windows não ficam nesta página. Para oferecer downloads,
crie uma **Release** do repositório e anexe um pacote ZIP com os dois programas.
O botão de lançamentos da página aponta para a lista de Releases.
